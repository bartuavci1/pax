backend kurulumu:
1. backend klasörüne gidin.
2. Terminali açın ve sanal ortam oluşturun: python -m venv .venv
3. Sanal ortamı aktif edin (Windows'ta: .venv\Scripts\activate ).
4. Gerekli kütüphaneleri yükleyin: pip install -r requirements.txt
frontend kurulumu: 
1. frontend klasörüne gidin.
2. Proje paketlerini yükleyin: npm install
uygulamayı başlatma: 
Terminal 1 (Backend):
cd backend
python -m uvicorn app.main:app --reload
Terminal 2 (Frontend):
cd frontend
npm start
